# Мобильное демоприложение

[Открыть приложение](https://ggrryrtj.github.io/tbank/mobile-demo/) · [Посмотреть анимацию](https://ggrryrtj.github.io/tbank/mobile-demo/?preview=success)

Отдельная мобильная версия интерфейса переводов: карточка операции, SVG-иконки, пружинящая галочка и её переход в маленький бейдж, маркированный образец квитанции.

Приложение работает локально в браузере. Все операции учебные, банковского подключения нет. Сохранённая история этой версии использует собственный ключ `tbank_mobile_demo_state`.

Параметры `preview=success`, `preview=result`, `preview=operation`, `preview=receipt` открывают примеры с вымышленными данными и не изменяют сохранённую историю. Для повторения анимации обновите страницу `?preview=success`.

Проверено в браузере на мобильных ширинах 320–430 CSS-пикселей. Реальный iPhone/Safari и Android-эмулятор пока не проверены.

## Исправление системной строки и высоты

- Нарисованные часы, батарея и значки связи убраны. В жёлтой плашке оставлено «Т-БАНК» по последнему уточнению пользователя; пометка «Учебный макет» находится внизу.
- Панели используют текущую высоту окна и безопасные отступы устройства. Белый фон продолжается под системной областью снизу, кнопки и меню учитывают место для подписи макета.
- В квитанции восстановлены формулировки эталона и изображение печати из предоставленного исходного проекта. Документ остаётся с водяными знаками «ОБРАЗЕЦ · ДЕМО»; экспорт также маркирован. Номер договора выводится только при наличии в данных операции.
- Проверены 320×667, 393×854 и 430×932, включая локальную имитацию верхнего/нижнего отступов 59/34 px. Повторная проверка на самом телефоне ещё предстоит.
